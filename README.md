# Joseph M. Gerrety

**Independent Mathematical Researcher**

I use Lean to examine what a mathematical inference requires. My research starts with a precise claim, constructs examples that test it, and traces the conclusion back to the hypotheses that support it. Each project below includes the proof source, a theorem index, and the records from independent proof checkers.

- [LIGO — Formal Lean Kernel Invalidation](https://github.com/josephmgerrety/LIGO-Formal-Lean-kernal-Invalidation) studies what model differences can tell us about a shared systematic error and which additional measurements restore identification.
- [Shor's Algorithm — Formal Lean Kernel Invalidation](https://github.com/josephmgerrety/SHOR-formal-lean-kernal-invalidation) gives a finite counterexample to a conditional probability bound in the 1994 discrete-logarithm analysis and derives its consequences for the good-sample argument.
